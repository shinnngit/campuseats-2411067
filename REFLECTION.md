# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?

 Imperative: I write every step for the browser. Declarative: I describe what the UI should look like and React does the steps.

2. Why must a component name start with a capital letter?

Lowercase names are treated as normal HTML tags, so React won't see it as my component.

3. What does a fragment <>...</> do, and why not just use a <div>?

It groups elements under one parent without adding an extra element to the page.

4. Name one benefit of splitting the UI into small components.
I can reuse them, and fix a bug in one place only.
